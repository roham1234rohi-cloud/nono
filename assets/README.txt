assets/logo.svg (or .png) -> your logo (set LOGO_SRC in js/app.js)
assets/hero.webp          -> hero artwork (set HERO_SRC in js/app.js)
assets/portfolio/         -> portfolio images, then set `image` in js/data.js

NEW in v5:
assets/fonts/Vazirmatn-Variable.woff2 -> (optional but recommended) download Vazirmatn and put it here
  so the font loads fast even when Google Fonts is slow/blocked.
